# PANAHANNET Panel

🚀 راهنمای نصب و دیپلوی

────────

## ⚡ نصب مستقیم روی VPS

```bash
curl -fsSL https://raw.githubusercontent.com/amirh00sain/SpiderPanel/main/start.sh | bash
```

> 💡 بعد از نصب، آدرس پنل و رمز عبور در انتهای خروجی نصب نمایش داده می‌شود.

────────

## 🚄 دیپلوی روی Railway

۱. پروژه را Fork کنید.
۲. وارد Railway شوید و با GitHub لاگین کنید.
۳. پروژه Fork‌شده را Deploy کنید.
۴. در Settings → Generate Domain یک دامنه بسازید و پورت را روی `8080` بگذارید.
۵. مسیر ورود به پنل را به انتهای آدرس اضافه کنید (پیش‌فرض `/panel`).

```text
https://your-domain.up.railway.app/panel
```

────────

## 🔐 ورود به پنل و مسیر ادمین

مسیر پیش‌فرض پنل `/panel` است و کاملاً قابل تغییر:

- از داخل پنل: بخش تنظیمات ← «مسیر ادمین» (پس از ذخیره، ری‌استارت لازم است)
- یا با متغیر محیطی: `PANEL_PATH=/your-secret-path`

────────

## 🔗 ساب‌لینک امن

ساب‌لینک هر کاربر/گروه به شکل هش امن ساخته می‌شود:

```text
https://domain.com/sub/<hash>
```

این هش از UUID اصلی کانفیگ جدا است، بنابراین لو رفتن ساب‌لینک باعث افشای UUID نمی‌شود.

────────

## 🛠️ متغیرهای محیطی مهم

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASSWORD` | رمز ورود ادمین | `admin` |
| `SECRET_KEY` | کلید امضای سشن‌ها | خودکار |
| `PANEL_PATH` | مسیر ورود به پنل | `/panel` |
| `PANEL_BRAND` | نام برند پنل | `PANAHANNET` |
| `BOT_TOKEN` | توکن ربات تلگرام | خالی |
| `ADMIN_IDS` | آیدی عددی ادمین‌های ربات (با کاما) | خالی |
| `SUPPORT_URL` | لینک پشتیبانی | کانال پیش‌فرض |
| `DATA_DIR` | مسیر ذخیره‌سازی | `/data` |

────────

## 📌 اطلاعات پروژه

- پورت پیش‌فرض: `8080`
- مسیر ورود به پنل: `/panel` (قابل تغییر)
- ساب‌لینک: `/sub/<hash>`
